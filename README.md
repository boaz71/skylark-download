# Skylark - download

Official site and download of **Skylark**, a light-aircraft flight simulator for Windows:
https://boaz71.github.io/skylark-download/

Get the game from the [latest release](https://github.com/boaz71/skylark-download/releases/latest):
`Skylark.zip` - unzip it and run `Skylark.exe`. The release notes list the zip's SHA-256.

This repository holds only the site and the release files, not the game's source.
